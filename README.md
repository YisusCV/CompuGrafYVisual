# CompuGrafYVisual
Examen T3 Curso Computacion Grafica y Visual

Descripción del juego:
  Un local de pizzería embrujado donde la única forma de salir es llegando a la zona de extracción o morir en el intento

Instrucciones de instalacion:
  Descargar carpeta ZIP/RAR
  Extraer la carpeta CompuGrafYVisual-main
  Ejecutar en Visual Studio Code

Controles:
  W Adelante
  S Atras
  A Izquierda
  D Derecha
  1 Arma 1 - Pistola
  2 Arma 2 - Escopeta
